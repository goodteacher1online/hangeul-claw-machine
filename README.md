# 3D 자음 뽑기 (Hangeul Claw Machine)

한글 자음(ㄱ~ㅎ)을 뽑는 3D 인형뽑기 게임입니다. 브라우저에서 바로 실행됩니다.

**▶ 플레이: https://goodteacher1online.github.io/hangeul-claw-machine/**

## 특징
- Three.js 기반 3D 인형뽑기 기계 (네온 조명, 인트로 360° 회전 연출)
- ㄱ~ㅎ 14개 자음 × 3개 = 42개의 3D 글자, 위아래로 쌓이는 물리
- 실제 집게처럼 손가락이 글자를 감싸 쥐어야 잡힘 (확률 뽑기 없음)
- 1~6인 차례 플레이, 플레이어별로 모은 자음 표시와 결과 보기 (플레이어를 클릭하면 모은 자음을 크게 보기 · 이름 고치기)
- 내부캠(드래그 회전) · 정면 · 측면 시점, 난이도(쉬움/보통/어려움), 글자 섞기
- 게임 시간 제한(제한 없음 · 3분 · 5분 · 10분), 시간이 끝나면 최종 순위와 우승자 발표
- [처음으로] 버튼으로 인원 · 이름 · 시간 설정 화면으로 돌아가기
- 휴대폰에서는 플레이어를 얇은 한 줄 띠로, 버튼은 [메뉴]로 접어서 기계가 잘 보이게
- 화면 캡처: 플레이어별로 모은 자음을 함께 담아 클립보드 복사 · PNG 저장 · 공유

## 조작
- 이동: 조이스틱 드래그 / 방향키 · WASD
- 잡기: 빨간 버튼 / Space
- 시점 전환: V, 글자 섞기: R, 화면 캡처: P, 처음으로: H
